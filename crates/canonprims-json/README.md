# canonprims-json

Canonical serialization for structured data (RFC 8785 and successors).

The RFC 8785 JSON Canonicalization Scheme (`jcs/rfc8785`) over a strict I-JSON loader. One pass validates and emits; nothing is silently repaired.

See the [canonprims repository](https://github.com/3leaps/canonprims) for the
specification, the conformance corpus and the Go implementation.
